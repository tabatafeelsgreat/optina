# Сайт прихода преподобного Иосифа Оптинского

Статический сайт (один файл `index.html`), публикуется через GitHub Pages.
Содержимое перенесено с russianchurchvb.org, дизайн по образцу hramantipa.ru.

## Админка
Содержимое (новости, расписание, праздники, сбор, объявление, галерея, тексты, контакты) меняется через https://app.pagescms.org — вход через GitHub, репозиторий optina. Настройки админки в `.pages.yml`, данные в `_data/*.json` и `_news/`. Сайт собирает Jekyll на GitHub Pages.
